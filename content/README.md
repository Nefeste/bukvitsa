# Задачи

Записи задач — по одной на файл YAML — правила, формат и источники в
[`../docs/09-content.md`](../docs/09-content.md). Коротко:

- `proverbs/`, `riddles/`, `extra/`, `words/`, `parts/` — по видам; номер в имени файла —
  вечный идентификатор вместе с папкой (`proverb-0001`).
- У каждой записи — источник с разделом или страницей, основание (общественное
  достояние) и `review: draft`; `checked` ставит человек после сверки со сканом.
- `notebooks.yaml` — тетради; `calendar.yaml` — задачи дня (только дописывается,
  выпущенные даты не меняются); `released.json` — выпущенные версии записей;
  `stoplist.txt` — слова, которых в задачах не бывает (ведёт владелец).
- Сборка: `bun tools/content/build.ts --check` (появится с 0.1).

нет): по ним проверяется формат.
