== Погода — стихии ==

: Около села лошадка весела (погода).
: Хмыль (Шмыг) под ворота, суконна (посконна) борода (погода).
: Выше леса, а тоньше волоса (ветер).
: Без рук, без ног воюет (ветер).
: Без рук, без ног, под окном стучит, в избу просится (ветер).
: Без рук, без ног, а ворота отворяет (ветер).
: Без рук, без ног, а на гору ползет (ветер).
: Матушкиной коробьи не подымешь, братова кушака не скатаешь, батюшкина коня не изловишь (земля, дорога, ветер).
: Отцова сундука не подымешь, матушкина столечника не скатаешь, братнина коня не обуздаешь (земля, снег, ветер).
: Царь кликнет, царь мигнет, кого-то позовет? (Гроза.)
: Что стучит без рук? (Гром.)
: Что без огня горит? (Гроза.)
: Сивый жеребец во (на) все царство ржет (гром).
: Кобыла заржет на турецкой горе, жеребец откликнется на Сионской горе (гром и молния).
: Тур ходит по горам, турица-то по долам, тур свистнет, турица-то мигнет (гроза).
: Гроб плывет, мертвец ревет, ладан пышет, свечи горят (туча, гром, молния).
: Без крыл летит (ветер), без ног бежит (туча), без огня горит (солнце), без ран болит (сердце).
: До неба достанет, а от земли не видать (дождь).
: Тонкий, высокий, упал в осоку, сам не вышел, а детей вывел (дождь и потоки).
: Шел долговяз, в сыру землю увяз (дождь).
: Тонок, долог, голенаст, а в траве не видать (дождь).
: На землю падает, от земли не отлетает (дождь).
: Скатерть бела, весь свет одела (снег).
: Ни хилела, ни болела, а саван надела (земля, снег).
: К божьему мясоеду гусей щиплют (снег идет).
: Летел порхан по всем торгам; бел балахон, без пол кафтан, без пуговиц (снег).
: Белый лебедь на яйцах сидит (поля, покрытые снегом).
: Зимой греет, весной тлеет, летом умирает, осенью оживает (снег).
: Увидел мать, умер опять (снег).
: На дворе в холоде горой, а в избе водой (снег).
: Летит — молчит, сядет — молчит, а помрет да сгниет, так и заревет (снег).
: Летел перхол, кафтан без пол, лег — шейку протянул, в щелку заглянул (вьюга).
: Внук по дедушку пришел (последний, вешний снег).
: Дедушка мост мостит без топора и без ножа (мороз).
: Старик у ворот тепло уволок (мороз).
: Стоит дуб без корня, без ветвей, сидит на нем птица вран; пришел к нему старик без ног, снял его без рук, заколол без ножа, сварил без огня, съел без зубов (мороз).
: Мостится мост без досок, без топора, без клина (лед).
: Стоит Ерман, на нем колпак: ни шит, ни бран, ни поярковый (снег на пне).
: Летом девица, зимой молодица (пень в снежном колпаке).
: Вечером наземь слетает, ночь на земле пребывает, утром опять улетает (роса).
: Заря заряница, красная девица, врата запирала, по полю гуляла, ключи потеряла, месяц видел, а солнце скрало (роса).
: Заря зарянка, ключи потеряла, месяц пошел, не нашел, солнце взошло, ключи нашло (роса).
: Живут четыре царя: который умрет из них, то все за ним в могилу пойдут (четыре стихии).
: Без рук, без ног, а на гору ползет (вода, ветер, огонь).
: В камне спал, по железу встал, по дереву пошел, как сокол полетел (огонь).
: Дрожит свинка, острая (золотая) щетинка (огонь).
: Красный кочеток по жердочке бежит (огонь).
: Я не сам по себе, а сильнее всего и страшнее всего, и все любят меня и все губят меня (огонь).
: Ударю я булатом по белым каменным палатам, выйдет княгиня и сядет на пуховую перину (огниво, кремень, трут, искра).
: Идет Егор с высоких гор, ковром покрыт, скобой прибит (подснежная вода).
: Без рук, без ног, на гору ползет (прибылая вода).
: Сям пересям, крыша нова, пересыпка бела (река и лед).
: Гола Матрена для всех страшна, а лубком покрыта — для всех ходка (замерзлая река).
: Шуба нова, на подоле дыра (прорубь).
: В новой стене, в круглом окне, днем стекло разбито, за ночь вставлено (прорубь).
: Кто мост мостит без ножа, без топора, без клиньев, без подклинков? (Лед.)
: Ни в огне не горит, ни в воде не тонет (лед).
: Бурко бежит, а оглобли стоят (река и берега).
: Сани бегут, самокатки бегут, а оглобли стоят (река и берега).
: Два братца в воду глядятся, век не сойдутся (речные берега).
: Один говорит: „Побежим, побежим“; другой говорит: „Постоим, постоим“, третий говорит: „Пошатаемся, пошатаемся“ (вода, берег, трава).
: Долгая долгушка, ты куда пошла? — А тебе, стрижена губа, что за нужда? (Река и обкошенные берега.)
: Еду, еду — следу нету; режу, режу — крови нету; рублю, рублю — щепок нету (вода).
: По какой дороге полгода ездят да полгода ходят? (По реке.)
: Ни море, ни земля; корабли не плавают, а ходить нельзя (лучина).
: В воде родился, огнем покормился (соль).
: В воде родился, а воды боится (соль).
: В земле родился, в огне крестился, на воду пал — весь пропал (соль).
: Лежит брус во всю Русь, а станет — до неба достанет (дорога).
: Бык на дворе, а рога на реку (дорога со двора).
: Чего к стене не прислонишь? (Дороги.)
: Кабы встал, я бы до неба достал; кабы руки да ноги, я бы вора связал; кабы рот да глаза, я бы все рассказал (дорога).
: Сестрину новину не скатать (дорога).
: Батюшкина коня не удержишь, матушкину покромку не скатаешь (ветер и дорога).
: Лежит Дороня (Дорофей), никто его не хороня(нит); а встанет, до неба достанет (дорога).
: Сам не видит, а другим указывает; нем и глух, а счет знает (верстовой столб).
