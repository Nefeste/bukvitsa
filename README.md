# Буквица

Словесные задачи на русском языке для RuStore: пословица с пропущенным словом, конец пословицы, пословица по
частям, лишняя буква. Пословицы — из сборника Владимира Даля «Пословицы русского народа» (1862): у каждой задачи
есть источник и раздел, ничего не придумано и не взято «из интернета». Игра студии «Горница»
([gornitsa.games](https://gornitsa.games)).

Состояние — [`STATUS.md`](STATUS.md), документы — [`docs/`](docs/README.md), правила для агентов — [`AGENTS.md`](AGENTS.md).

Expo / React Native / TypeScript, Android, без сервера и без сети.

## Версии

Номер версии — в `app.json`, `package.json`, `package-lock.json`, `src/version.ts` и `STATUS.md`
([`docs/05-process.md`](docs/05-process.md#версии)). У каждой версии — раздел ниже: что изменилось для игрока.

### 0.1.0 — каркас игры

- Задачи дня: пять задач, одни на всех, по дате телефона; итог — кружками, им можно поделиться текстом.
- Восемь тетрадей по 30 задач: «Зима и праздники», «Ученье и ум», «Труд и мастерство», «Дом и гости»,
  «Дорога и погода», «Счастье и удача», «Слово и правда», «Звери и птицы».
- Четыре вида задач: пропущенное слово из ряда букв, конец пословицы из четырёх, пословица по частям,
  лишняя буква. Подсказки бесплатные; «Показать ответ» — всегда.
- Прошлые дни — с 1 декабря 2026 года; пропущенный день ждёт.
- «Меньше движения» в настройках; «Об игре» — откуда пословицы.
