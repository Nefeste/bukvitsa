# Складно («Буквица»)

Игра называется **«Складно»** (решение владельца 08.11.2026, #2); в коде и документах — рабочее имя «Буквица»
(`bukvitsa`), см. [`docs/01-product.md`](docs/01-product.md), «Название».

Словесные головоломки на русском языке — шестая игра студии «Горница»
([gornitsa.games](https://gornitsa.games/)). Пословица с пропущенным словом, загадка,
пословица с лишней буквой, старое слово по Далю, пословица по частям — ответ складывается
из ряда букв или выбирается из четырёх, за минуту. Тексты — из «Пословиц русского
народа» и «Толкового словаря» Владимира Даля и загадок Дмитрия Садовникова; после
каждой задачи — откуда она и что значит. Каждый день — одна задача дня, общая для всех,
с результатом, которым можно поделиться текстом. Без интернета, без регистрации, без
таймеров. Реклама — только между задачами и никогда после задачи дня; одна покупка
«Складно+» убирает её навсегда. Android, RuStore; веб-сборка. Expo / React Native /
TypeScript.

**Состояние** — версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md).
Разработка открыта 08.11.2026 (решение владельца, Nefeste/uprava#80).

## Чем отличается

1. **Задачи — из Даля, а не из словаря слов.** В RuStore пять сотен игр «в слова»
   с одним и тем же содержанием; пословицы, загадки и старые слова с источником
   не делает никто ([`docs/11-market.md`](docs/11-market.md)).
2. **Реклама, на которую не жалуются.** Между задачами, не в первый день, не чаще раза
   в три минуты, никогда посреди задачи и никогда у задачи дня; «Буквица+» — одна покупка,
   не подписка. Подсказки бесплатны и не продаются ([`docs/adr/0003-money-ads-plus.md`](docs/adr/0003-money-ads-plus.md)).
3. **Ничего не сгорает.** Пропущенный день ждёт в архиве; ни серий, ни энергии, ни
   уведомлений «мы соскучились».

## Как собрать

```bash
npm ci
npm run content                                  # content/ → src/content/generated/pack.ts
npm run typecheck && npm run lint && npm test
EXPO_OFFLINE=1 npm run export:web && npm run e2e # веб-сборка и сценарий в браузере
```

Все команды — в [`AGENTS.md`](AGENTS.md), «Commands», и в [`docs/05-process.md`](docs/05-process.md).
На каждый PR CI проверяет содержание, типы, линтер и тесты (`.github/workflows/pr.yml`, из набора
студии `gornitsa-kit`). PR без путей владельца из `.github/CODEOWNERS`
сливается сам после зелёных проверок и метки `ревью: ок` от Ревьюера (`automerge.yml`; метки пока нет — решение владельца #10, PR сливает он);
с путями владельца — его сливает владелец ([`docs/05-process.md`](docs/05-process.md),
«Ветки»).

## Версии

Номер версии — в `app.json`, `package.json`, `package-lock.json`, `src/version.ts` и `STATUS.md`
([`docs/05-process.md`](docs/05-process.md)). У каждой версии — раздел: что изменилось для игрока.

### Готовится 0.3.0

- «Сообщить об ошибке» — в настройках и под «Откуда это»: отчёт с номером задачи, его видно целиком до отправки.

### 0.2.0 — тёмная тема, «ещё крупнее», «Буквица+» и сохранение

Первая сборка для телефона (APK на тег, предвыпуск в GitHub; задачи — ещё черновики, не сверенные со сканом).

- Шестой вид — «Конец пословицы»: начало пословицы и четыре конца на выбор.
- «Буквица+» (249 ₽, навсегда, не подписка), реклама только между задачами тетради, «десять задач за ролик».
- Тёмная тема (как в телефоне или своя) и «ещё крупнее» — текст и плашки на четверть крупнее.
- Прогресс хранится в одном файле сохранения со списком решённых задач; решённое в 0.1 переносится само.
- «Удалить мои данные» в настройках — с подтверждением.
- Оценка в RuStore — один раз, после второй решённой тетради.
- Прогресс переживает переустановку: он входит в резервную копию Android.
- Заставка без белой вспышки; тема «как в телефоне» работает и на Android.

### 0.1.0 — движок, задачи из Даля и первые экраны

- Пять видов задач на четырёх взаимодействиях: пословица с пропуском и загадка — ряд букв, старое
  слово — выбор из четырёх, лишняя буква — найти в строке, по частям — расставить части.
- Три подсказки по порядку — «Убрать лишние», «Открыть букву», «Показать ответ»; бесплатно.
- Задача дня — одна на всех, вид по дню недели; «Откуда это» и «Поделиться» текстом; архив.
- Первая тетрадь — все пять видов; остальные — «В следующих версиях».
- Задачи — черновики из «Пословиц русского народа» Даля (текст Викитеки), ещё не сверены со сканом.
