# Буквица

Словесные головоломки на русском языке — шестая игра студии «Горница»
([gornitsa.games](https://gornitsa.games/)). Пословица с пропущенным словом, загадка,
пословица с лишней буквой, старое слово по Далю, пословица по частям — ответ складывается
из ряда букв или выбирается из четырёх, за минуту. Тексты — из «Пословиц русского
народа» и «Толкового словаря» Владимира Даля и загадок Дмитрия Садовникова; после
каждой задачи — откуда она и что значит. Каждый день — одна задача дня, общая для всех,
с результатом, которым можно поделиться текстом. Без интернета, без регистрации, без
таймеров. Реклама — только между задачами и никогда после задачи дня; одна покупка
«Буквица+» убирает её навсегда. Android, RuStore; веб-сборка. Expo / React Native /
TypeScript.

**Состояние** — версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md).
**Кода пока нет**: репозиторий заполнен документами, спецификациями и решениями
(решение владельца 04.10.2026).

## Чем отличается

1. **Задачи — из Даля, а не из словаря слов.** В RuStore пять сотен игр «в слова»
   с одним и тем же содержанием; пословицы, загадки и старые слова с источником
   не делает никто ([`docs/11-market.md`](docs/11-market.md)).
2. **Реклама, на которую не жалуются.** Между задачами, не в первый день, не чаще раза
   в три минуты, никогда посреди задачи и никогда у задачи дня; «Буквица+» — одна покупка,
   не подписка. Подсказки бесплатны и не продаются ([`docs/adr/0003-money-ads-plus.md`](docs/adr/0003-money-ads-plus.md)).
3. **Ничего не сгорает.** Пропущенный день ждёт в архиве; ни серий, ни энергии, ни
   уведомлений «мы соскучились».

## Как собрать

Пока нечего: команды появятся с 0.1 ([`docs/07-roadmap.md`](docs/07-roadmap.md)). Задуманный
набор — в [`AGENTS.md`](AGENTS.md), «Commands», и в [`docs/05-process.md`](docs/05-process.md).

На каждый PR CI проверяет типы, линтер, тесты и сборку задач (`.github/workflows/pr.yml`;
пока кода нет — отвечает «зелёным»). PR без путей владельца из `.github/CODEOWNERS`
сливается сам после зелёных проверок и метки `ревью: ок` от Ревьюера (`automerge.yml`);
с путями владельца — его сливает владелец ([`docs/05-process.md`](docs/05-process.md),
«Ветки»).
