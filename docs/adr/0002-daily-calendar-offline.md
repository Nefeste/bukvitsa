# 0002. Задача дня — из календаря, собранного при сборке; сервера нет; выпущенный календарь не меняется

**Решили.**

- Задача дня назначается **календарём** `content/calendar.yaml` («дата → id записи»),
  который собирает команда `tools/content/calendar.ts` на три года вперёд из записей
  с `daily: yes` и `review: checked`, с чередованием видов по дням недели
  (`08-game-design.md`, «Задача дня»). Календарь встраивается в приложение вместе
  с задачами.
- День определяется по часам телефона; сервера, который «раздаёт» задачу дня, нет —
  как нет и никакого сервера у игры (`03-server-api.md`).
- **Выпущенная дата календаря не меняется никогда**: команда только дописывает даты
  в конец; золотой тест держит выпущенные даты; `content/calendar.yaml` — путь владельца
  в `CODEOWNERS`. Ошибка в задаче исправляется новой `version` записи под тем же `id`
  (ADR студии 0004) — дата при этом указывает на ту же запись.
- Архив прошлых задач дня — бесплатный и полный; будущие даты игра не показывает.

**Почему.**

- Сервер ради одной строки в день — это машина, домен, журнал, политика, совместимость
  версий и дежурство; для игры, которая должна окупиться с первых месяцев, это худшая
  из трат. Календарь на три года закрывает ту же потребность ценой одного файла.
- Одна задача у всех в один день — суть формата «поделиться результатом»: у всех
  должен быть один и тот же ряд букв. Календарь это гарантирует, а генерация на
  телефоне — нет (разные версии, разные наборы).
- Неизменность выпущенных дат — чтобы игрок, который решил задачу 5 октября, в любой
  версии видел в архиве ту же задачу, и чтобы «поделиться» не расходилось у игроков
  с разными версиями.

**Платим.**

- Переведённые часы показывают «завтрашнюю» задачу. Соревнования нет, обмануть некого,
  кроме себя; принято.
- Календарь надо дописывать раньше, чем он кончится: тест проверяет запас ≥ 365 дней,
  и выпуск с меньшим запасом — красный.
- Новая задача дня появляется у игрока только с новой версией игры, если его день уже
  за концом встроенного календаря, — отсюда запас в три года.
- Если в выпущенной дате стоит задача, которую пришлось снять (например, по правилу
  §2 `09-content.md`), снять её нельзя — только исправить текст новой версией записи.
  Отбор до выпуска поэтому строже, чем для тетрадей.

**Когда пересмотреть.** Если понадобится менять задачи дня без выпуска версии (события,
праздники) чаще раза в месяц — это повод для сервера наборов по образцу «Узоров»,
новым ADR; выпущенные даты и тогда остаются неизменными.
