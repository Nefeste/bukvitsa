# 0004. Expo / React Native / TypeScript, как у соседей; интерфейс на компонентах и SVG, без Skia; экраны без роутера

*Общее правило — ADR студии [0003](https://github.com/Nefeste/gornitsa/blob/main/adr/0003-expo-stack-ci.md)
(стек, генерируемые нативные папки, сборка без EAS). Здесь — что выбрано внутри него.*

**Решили.**

- Expo SDK 57 (как у соседей на 04.10.2026), React Native, TypeScript; `android/`
  и `ios/` генерируются; плагины конфигурации — для подписи, RuStore Pay, рекламного
  SDK и правил резервной копии.
- **Без Skia.** Весь интерфейс — компоненты React Native и `react-native-svg`: плашки
  букв, узорные буквы, обложки тетрадей, орнаментная полоса. Шейдеров и канвы нет.
- **Экраны переключаются состоянием**, без роутера — как в «Вотчине» и «Узорах».
- Звук — `expo-av` с двумя короткими файлами, синтезированными своим кодом; на вебе —
  те же файлы.

**Почему.**

- В «Буквице» нет ничего, что требует Skia: ни канвы с тысячами клеток, ни шейдеров.
  Skia — это CanvasKit в вебе (мегабайты, отдельная загрузка), свои подводные камни
  на Android (у «Узоров» — отдельный раздел) и ещё одна зависимость, за версией
  которой надо следить. Для десятка плашек и орнамента SVG достаточно и одинаково
  работает в вебе и на телефоне ([0007](0007-web-first-class.md)).
- Роутер — лишний слой для шести экранов; опыт соседей показал, что состояние проще
  тестировать и не ломает веб-сборку.
- Один стек со всеми играми — копирование инфраструктуры без переделок (ADR студии 0002).

**Платим.**

- Анимации — Reanimated и SVG, без шейдерной «магии»: встряхивание ряда, появление
  карточки «Откуда это» — просто, но не более того.
- Если когда-нибудь понадобится сложная графика (например, рисованные буквицы с
  эффектами), её придётся добавлять как отдельный модуль — или признать, что это
  не «Буквица».

**Когда пересмотреть.** Если соседи перейдут на новый SDK Expo — вместе с ними,
отдельным PR, после проверки сборки.
