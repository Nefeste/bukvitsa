# 0009. Пятое взаимодействие — «Тайнопись»: буква на все клетки одного числа

Дополняет ADR [0005](0005-five-kinds-four-interactions.md): там новое взаимодействие — только отдельным ADR.
Решение владельца 08.11.2026 — «Тайнопись» в 1.0 (Issue #12, вариант 2). Спецификация —
[`../specs/2026-11-cipher.md`](../specs/2026-11-cipher.md).

**Решили.**

- Пятое взаимодействие — **«буква на число»**: пословица клетками с числами, экранная клавиатура алфавита; буква
  ставится во все клетки выбранного числа, одна буква — одно число. Им пользуется один вид — «Тайнопись».
- Всё остальное по ADR 0005 не меняется: числа букв и открытые с начала буквы **готовит сборка** от
  `sha256(id:version)`, движок ничего не перемешивает и не выбирает; подсказки — те же три.
- Других новых взаимодействий к 1.0 нет. Следующее (путь по сетке для филворда) — снова отдельным ADR.

**Почему.**

- Криптограмма — в пятёрке словесных игр России (`11-market.md`), а наш контент — пословица Даля с источником —
  подходит к ней лучше всех: ответ один, словарь не нужен.
- Взаимодействие маленькое: клетки и плитки букв уже есть у ряда букв, новое — только «одна буква на все клетки
  числа». Это один набор функций движка, один экран-состояние и одна клавиатура.

**Платим.**

- Пятое состояние экрана «Задача» и пятый набор тестов; клавиатура на 33 клавиши, которую надо уместить на 360 dp
  при «ещё крупнее».
- Новая проверка «виртуального игрока»: второй ответ ищется по узору чисел среди всех пословиц сборника.
- Около 2–3 дней работы, снятых со сквозного пути к модерации 05–07.12 (владелец это принял в #12).

**Когда пересмотреть.** Если на закрытом тесте «Тайнопись» решают реже остальных видов или дольше пяти минут —
сначала правило открытых букв (`08-game-design.md`), потом вопрос, нужен ли вид.
