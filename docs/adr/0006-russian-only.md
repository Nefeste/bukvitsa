# 0006. Один язык — русский; английской версии и зарубежных сборок нет

*Соотносится с ADR студии [0014](https://github.com/Nefeste/gornitsa/blob/main/adr/0014-two-regions.md)
(зарубежным игрокам — свои сборки): для «Буквицы» зарубежной сборки не будет.*

**Решили.**

- Интерфейс и контент — только на русском. `src/i18n/` остаётся (правило студии: строки
  для игрока в одном месте), но второго языка в нём нет.
- Сборки для других стран, перевода и «адаптации» задач нет и не планируется.
- Страница игры на сайте — на русском и английском (у сайта два языка), английская
  говорит прямо: игра на русском языке, для тех, кто его знает.

**Почему.**

- Контент игры — сам русский язык: пословицы, загадки, старые слова по Далю. Перевод
  уничтожает задачу; «английская версия» была бы другой игрой с другими источниками.
- Зарубежная сборка по ADR 0014 — это отдельный сервер, магазины, право; для игры без
  сервера и с русским содержанием это трата без смысла. Русскоязычные игроки за рубежом
  — это вопрос дистрибуции (Яндекс Игры открыты из многих стран), а не сборки.

**Платим.**

- Рынок ограничен русскоязычными; это осознанно — ниша без зарубежных конкурентов
  (`11-market.md`).
- Английская страница сайта честно отсекает часть посетителей.

**Когда пересмотреть.** Если студия сделает игру того же устройства на другом языке —
это будет отдельный проект, а не версия «Буквицы».
