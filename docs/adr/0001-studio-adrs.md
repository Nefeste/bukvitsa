# 0001. Какие ADR студии применяются и как именно

*Записка по правилу устава ([`docs/04-process.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/04-process.md),
«Новый проект», п. 3): без пересказа решений студии — только то, как они выполнены
в «Буквице». Сами решения — в [`adr/`](https://github.com/Nefeste/gornitsa/blob/main/adr/README.md)
устава.*

**Решили** (04.10.2026, решение владельца о шестой игре). «Буквица» — отдельный
репозиторий `Nefeste/bukvitsa`, игра студии «Горница»; все ADR студии 0001–0019 действуют.
Как они применены:

| ADR студии | В «Буквице» |
|---|---|
| 0001 устав | `AGENTS.md` начинается с блока устава; правила студии здесь не пересказываются |
| 0002 копирование | инфраструктура — копиями с пометкой источника: список в `02-architecture.md`, «Что берём у соседей»; workflow — из `gornitsa-kit`, когда появятся |
| 0003 стек | Expo SDK 57 / React Native / TypeScript; `android/`, `ios/` генерируются; APK — CI на тег ([0004](0004-expo-no-skia.md)) |
| 0004 чистый движок, снимки | `src/engine/` без React, времени и случайности; ряд букв и перемешивание — из сборки ([0005](0005-five-kinds-four-interactions.md)); сохранение — список событий со `schema` и миграциями; `id` записей вечные, исправление — новая `version` |
| 0005 без сети, свой сервер | сервера нет вовсе ([0002](0002-daily-calendar-offline.md)); если появится — на машине студии в России |
| 0006 идентификатор и ключ | `games.gornitsa.bukvitsa` и постоянный ключ подписи — с первой сборки, которую кто-то поставил на телефон (0.2) |
| 0007 профиль без регистрации | профиля нет совсем: ни ключа устройства, ни ника — нечему быть |
| 0008 минимум данных | SDK аналитики нет; своей статистики на сервере нет; единственный сторонний SDK с сетью — рекламный, как разрешено для игры с рекламой; что он получает — в политике |
| 0009 деньги | реклама только между задачами, не в первый день, одна покупка «Буквица+» убирает её навсегда; ролик за награду — только по желанию и не за силу; ни валюты, ни подсказок за деньги ([0003](0003-money-ads-plus.md)) |
| 0010 без давления | ни таймеров, ни жизней, ни серий; архив задач дня бесплатный — пропущенный день не теряется; «десять задач за ролик» — счётчик, не срок; покупка предлагается в трёх местах из `08-game-design.md` |
| 0011 честная игра | случайности, решающей исход, нет; бота нет; чата нет |
| 0012 контент | только Даль, Садовников, Михельсон — общественное достояние с разделом и страницей; записи `review: draft` → `checked` человеком; картинки только кодом (`09-content.md`) |
| 0013 «Сени» | отзывы и письма — через шлюз, отправляет владелец |
| 0014 два региона | зарубежных сборок нет ([0006](0006-russian-only.md)); данные игроков никуда не уходят |
| 0015 сайт из `store/` | `store/site/page.ru.md` и `.en.md` по формату устава; пока игра «В планах», карточка на сайте написана руками в репозитории сайта |
| 0016 онлайн с 14 лет | онлайна нет |
| 0017 видимость | репозиторий закрывается после работ над сайтом (решение владельца 04.10.2026); до того в нём нет ничего, чего не было бы на сайте |
| 0018 классы изменений | `.github/CODEOWNERS` с путями владельца + свои: `plugins/`, `content/calendar.yaml`; `automerge.yml` и скрипт — копия из «Узоров» |
| 0019 CI на PR | `pr.yml`: типы, линтер, тесты, сборка контента; APK — только на тег; `runs-on: ubuntu-24.04` |

**Почему** так, а не иначе: «Буквица» нарочно самая простая игра студии — без сервера,
без профиля, без онлайна, — чтобы окупиться в первые месяцы. Каждое «нет» в таблице —
это неделя работы, которой не будет.

**Платим.** Копии инфраструктуры стареют так же, как у соседей; рекламный SDK —
единственное место, где студия берёт чужой код с сетью, и его обновления — наша забота.

**Когда пересмотреть.** Появление сервера, онлайна или профиля — новый ADR и правка
строк 0005, 0007, 0016 этой таблицы.
