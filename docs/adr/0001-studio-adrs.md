# 0001. Какие ADR студии действуют здесь и как

Общие решения — в уставе, `adr/` (https://github.com/Nefeste/gornitsa/tree/main/adr); здесь они не пересказываются,
только как применены.

| ADR студии | Здесь |
|---|---|
| 0002 — код копируется с пометкой источника | каркас из «Наготове», хеш и генератор — из «Сказов» и «Анамнеза»; список — [`02-architecture.md`, §2](../02-architecture.md#2-что-скопировано-из-игр-студии-adr-студии-0002) |
| 0003, 0019 — Expo, нативные папки генерируются, CI на PR, APK только на тег | Expo SDK 57; `pr.yml` на каждом PR, `android.yml` только по тегу — [`05-process.md`](../05-process.md) |
| 0004 — чистый детерминированный движок | `src/engine/`: дата — аргументом, порядок плиток и вариантов — из хеша задачи |
| 0005 — без сети по умолчанию | сервера нет; в 0.x релиз без `INTERNET`; реклама в 1.0 — решение владельца |
| 0006 — постоянный идентификатор и ключ | предложен `games.gornitsa.bukvitsa` — подтверждает владелец до первого подписанного APK |
| 0008 — данные минимум | игра ничего не отправляет и не собирает |
| 0009 — деньги не покупают преимущество | подсказки бесплатны и не продаются; «Буквица+» — только «без рекламы» — [`10-money.md`](../10-money.md) |
| 0010 — без давления | ни таймеров, ни жизней, ни серий; пропущенный день ждёт |
| 0012 — контент из названных источников | пословицы — только из Даля 1862 года, скачанного текста; `review: draft` — [`09-content.md`](../09-content.md) |
| 0017 — видимость | репозиторий открыт; ничего личного и закрытого в нём нет (модель телефона владельца — только в управе) |
| 0018 — права по классам | пути владельца — `.github/CODEOWNERS` |
| 0022 — набор `gornitsa-kit` | CI, ключ, подпись, проверки APK, загрузка в RuStore; RuStore Pay — оттуда же (0.3) |
| 0023 — графика | рисунок кодом, токены студии, три эталонных кадра — [`13-art.md`](../13-art.md); как выполнены правила — [`02-architecture.md`, §4](../02-architecture.md#4-графика-adr-0023-устава) |
