# Как устроено

Кода ещё нет: документ описывает принятое устройство. С первой строки кода он описывает
то, что есть; расхождение с кодом правится в том же коммите.

«Буквица» — нарочно **маленькое** приложение: несколько экранов, чистый движок задач,
встроенный набор контента, две точки, где есть деньги (покупка и реклама). Сервера нет.
Всё, что не про задачи, — диалог, тексты, хранилище, настройки, журнал сбоев, подпись,
CI, загрузка в RuStore, RuStore Pay — берётся у соседей копированием (ADR студии 0002,
[ADR 0001](adr/0001-studio-adrs.md)).

## Главная мысль: задача — данные, прогресс — список событий

Задача — неизменяемая запись, собранная из `content/` при сборке: условие, ответ, ряд
букв, варианты, источник. Прогресс игрока — **список событий** «задача X решена
дд.мм.гггг с N попытки с подсказками K» и «задача Y подсмотрена»; всё остальное
(«12 из 40», значки, архив) выводится из него. Список переживает любые версии задач:
событие ссылается на `id`, а не на содержимое.

## Слои

```
src/engine/     задачи, проверка ответа, подсказки, календарь, правила рекламы — чистый TypeScript
src/content/    generated/pack.ts — встроенный набор (не в git), типы записей
src/state/      прогресс (события), настройки, права («Буквица+», открытые десятки), хранилище
src/screens/    главная, задача, откуда это, тетрадь, архив, «Буквица+», настройки, об игре
src/ui/         общие элементы: плашка-буква, диалог, тема, узорная буква и обложки (SVG)
src/money/      RuStore Pay (покупка, восстановление) и адаптер рекламы — путь владельца
src/i18n/       тексты интерфейса (русский); контент задач — в content/
```

- **Движок чистый** (ADR студии 0004): без React, без `Date.now()`, без `Math.random()`.
  Сегодняшняя дата, права игрока и прогресс — аргументы. `engine.check(task, answer)`,
  `engine.hint(task, state, n)`, `engine.daily(calendar, date)`, `engine.adAllowed(progress,
  settings, now)` — функции, которые проверяются тестами на образцах.
- **Правила рекламы — в движке**, не в экране: `adAllowed` отвечает по событиям
  прогресса и по времени последнего ролика (аргумент), и тест держит все границы из
  [`08-game-design.md`](08-game-design.md), «Реклама».
- **Экраны переключаются состоянием**, без роутера — как в «Вотчине» и «Узорах»
  (ADR [0004](adr/0004-expo-no-skia.md)).

## Контент в приложении

Встроенный набор `src/content/generated/pack.ts` собирает `bun tools/content/build.ts`
([`09-content.md`](09-content.md), §4). В набор входят задачи, тетради, календарь.
Размер — около 150 КБ на 1100 задач (оценка): весь контент всегда с приложением, ничего
не докачивается. Новые тетради приходят с новой версией игры из RuStore.

## Права игрока

Права — функция от трёх вещей и считаются на телефоне (ADR студии 0009: сервер о покупках
не знает):

| Право | Откуда |
|---|---|
| без рекламы | «Буквица+» куплена (RuStore Pay, сверка при запуске и по «Восстановить покупки») |
| тетрадь открыта | первая тетрадь — всегда; остальные — «Буквица+» или открытые десятки |
| открытые десятки | счётчик по тетради: «открыто 20 задач» после двух роликов; хранится в состоянии |
| задача дня и архив | всегда |

Состояние покупки хранится на телефоне с последней датой сверки; без сети игра верит
сохранённому. Как это устроено в RuStore Pay — копия из «Нард» (`src/money/pay.ts`).

## Реклама

`src/money/ads.ts` — адаптер с двумя функциями: `showInterstitial()` и `showRewarded()`,
обе возвращают результат («показан», «нет ролика», «отменён»). Внутри — SDK рекламной
сети, **тот же, что в «Нардах»** (какой — `docs/11-money.md` «Нард»; на 04.10.2026 —
сверить, там он ещё подключается). Экран вызывает адаптер только когда движок разрешил
(`adAllowed`), и никогда внутри задачи. SDK подключается плагином конфигурации Expo;
в веб-сборке адаптер — заглушка «нет ролика» до появления веб-рекламы Яндекс Игр
([`07-roadmap.md`](07-roadmap.md), 1.2).

Рекламный SDK — единственная сторонняя библиотека в игре, которая выходит в сеть;
что он передаёт и какое разрешение требует (`AD_ID`) — [`10-money.md`](10-money.md),
«152-ФЗ», и раздел игры в политике конфиденциальности.

## Хранилище

Копия из «Вотчины» (`src/state/storage.ts`): файл JSON в папке приложения, запись
атомарная, версия схемы и миграции ([`04-data-model.md`](04-data-model.md)). Автобэкап
Android включён (правила резервной копии — плагином, как у «Узоров»): прогресс
переезжает на новый телефон вместе с аккаунтом Google игрока; «Буквица+» восстанавливается
через RuStore. Своего облака нет.

## Веб-сборка

Expo для веба собирает то же приложение (ADR [0007](adr/0007-web-first-class.md)):

- **закрытая проверка** с компьютера — `gornitsa.games/bukvitsa/test/` под паролем, как
  у «Узоров» (`site.yml`, ветка `vps`), с 0.2;
- **сценарий Playwright** на веб-сборке — часть проверок перед push ([`06-testing.md`](06-testing.md));
- **Яндекс Игры** — та же сборка с SDK площадки, после 1.0 ([`07-roadmap.md`](07-roadmap.md), 1.2).

Поэтому в ядре нет ничего только-нативного: SVG вместо Skia, звуки через `expo-av`
с заглушкой на вебе, покупка и реклама — за адаптерами с веб-заглушками.

## Что берём у соседей

Копированием, с пометкой источника в первой строке (ADR студии 0002):

| Что | Откуда |
|---|---|
| диалог, механика текстов, журнал сбоев и «Сообщить об ошибке», хранилище, настройки, тема | `Nefeste/votchina` |
| плагин подписи, `android.yml` (сборка на тег), `rustore.yml` (загрузка в RuStore), `site.yml` (закрытая веб-версия), `pr.yml`, `automerge.yml`, `automerge.ts` | `Nefeste/uzory` |
| RuStore Pay (покупка, восстановление), RuStore Review, рекламный адаптер и его плагин | `Nefeste/nardy` |
| сборка контента из YAML с проверками и отчётом, «виртуальный игрок» как образец | `Nefeste/uzory` (`tools/content/`), `Nefeste/skazy` |

Сначала переносятся workflow — когда они появятся в `gornitsa-kit`, копировать их больше
не нужно (пересмотр ADR 0002 от 03.10.2026).

## Сборка приложения

Expo SDK 57, React Native, TypeScript — как у соседей (ADR студии 0003; ADR
[0004](adr/0004-expo-no-skia.md)). Папки `android/` и `ios/` генерируются; нативное —
в `app.json` и плагинах. APK собирает CI на тег версии постоянным ключом из секретов
(ADR студии 0006, 0019); на PR — только типы, линтер и тесты. `applicationId` —
`games.gornitsa.bukvitsa`, навсегда.

## Ограничения, о которых стоит помнить

- Всё в одной сборке: 1100 задач — 150 КБ, но 10 000 задач с картинками — уже вопрос
  о наборах с сервера, как у «Узоров». До 1.3 это не нужно.
- Задача дня по часам телефона: переведённые часы покажут «завтрашнюю» задачу. Это
  принято осознанно (ADR [0002](adr/0002-daily-calendar-offline.md)): сервера нет,
  соревнования нет, обмануть некого, кроме себя.
- Рекламный SDK — чужой код в приложении: его обновления, разрешения и поведение
  на старых Android — наш риск; версия закреплена и меняется отдельным PR.
- Веб-сборка и нативная должны оставаться одним кодом: «только на телефоне» — всегда
  за адаптером, и сценарий Playwright это проверяет.
