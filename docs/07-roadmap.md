# Дорожная карта

Этапы и что в них входит. Текущие задачи — на доске «Горница» (Issues), вопросы
владельцу — Issues с меткой `владелец`; здесь — план и таблица вопросов с решениями.
Сроков нет: по правилу студии дата называется, когда в ней уверены. Порядок версий —
по росту риска: сначала движок и контент (дёшево и проверяемо), потом экраны, потом
деньги.

### Ассистенту — первым делом (когда владелец откроет разработку)

1. Скопировать инфраструктуру из соседей по списку [`02-architecture.md`](02-architecture.md),
   «Что берём у соседей» (или взять из `gornitsa-kit`, если уже там).
2. Спецификация [`specs/2026-10-engine.md`](specs/2026-10-engine.md) → движок и тесты (0.1).
3. Конвейер контента и первые две тетради из `content/` (0.1–0.3).

## 0.1 — движок и четыре взаимодействия

Чистый движок пяти видов задач, сборка контента из YAML с проверками, «виртуальный
игрок», веб-прототип одного экрана «Задача» для проверки руками. Без экранов, денег,
звука. Спецификация — [`specs/2026-10-engine.md`](specs/2026-10-engine.md),
[`specs/2026-10-content-pipeline.md`](specs/2026-10-content-pipeline.md).

## 0.2 — экраны и первая тетрадь

Главная, задача, «Откуда это», тетрадь, настройки, «Об игре»; хранилище и миграции;
тема и крупный шрифт; первая тетрадь (40 задач, `checked`); APK на тег; закрытая
веб-версия на сайте. Спецификация — [`specs/2026-10-screens.md`](specs/2026-10-screens.md).

## 0.3 — контент: восемь тетрадей

Восемь тетрадей и пул задач дня на год (≈ 700 записей, `checked`); отбор по
[`09-content.md`](09-content.md), §2; стоп-лист; обложки кодом. Это самый долгий этап:
скорость — темп сверки владельцем (В9).

## 0.4 — задача дня, архив, «Поделиться»

Календарь на три года, архив, текст «Поделиться», чередование видов. Спецификация —
[`specs/2026-10-daily.md`](specs/2026-10-daily.md).

## 0.5 — деньги

Рекламный адаптер и SDK (копия из «Нард»), правила показа в движке, экран согласия,
ролик по желанию (если В3 — да), «Буквица+» через RuStore Pay, «Восстановить покупки».
Спецификация — [`specs/2026-10-money.md`](specs/2026-10-money.md).

## 0.6 — к закрытому тесту

Страница игры на сайте (`store/site/`), раздел политики с рекламой, анкеты `forms.md`,
снимки, RuStore Review, звуки, проверка на телефонах; закрытый тест 2 недели по
ориентирам [`11-market.md`](11-market.md).

## 1.0 — первый выход в RuStore

Ворота — [`specs/2026-10-v1.md`](specs/2026-10-v1.md). После выхода — замеры четыре
недели: установки, удержание, eCPM, покупки; документы `08`, `10`, `11` правятся по
данным.

## 1.1 — «шире»

Новые тетради (фразеологизмы по Михельсону, загадки Садовникова — после сверки
источников), достижения без давления («Решена тетрадь», «Сто задач дня»), платные
тетради по отдельности — по итогам замеров.

## 1.2 — Яндекс Игры

Та же веб-сборка с SDK площадки: её реклама и покупки; страница на площадке.

## 1.3 — вопрос

«Вдвоём на одном телефоне» (одна задача по очереди) — без сервера; всё, что требует
сервера, — только новым ADR ([`03-server-api.md`](03-server-api.md)).

## Не планируется

- Онлайн с чужими людьми, рейтинги, лиги, профили.
- Генерация задач, картинки из генераторов, тексты «из интернета».
- Подписка, валюта, подсказки за деньги, таймеры и серии.
- Английская версия и сборки для других стран (ADR [0006](adr/0006-russian-only.md)).

## Замеры после выхода (первые 4 недели)

По [`08-game-design.md`](08-game-design.md), «Как поймём…» и [`11-market.md`](11-market.md),
«Как поймём, что выбор верный». Источники цифр: статистика RuStore, отчёт рекламной сети,
строка «Об игре» от тестеров и отзывы. Итог — запись в журнале и правки гипотез.
