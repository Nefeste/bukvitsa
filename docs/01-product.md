# Что это за продукт

**«Буквица»** — словесные головоломки на русском языке для телефона. Задача — пословица
с пропущенным словом, загадка, пословица с лишней буквой, старое слово по Далю или
пословица, рассыпанная на части. Ответ складывается из ряда букв или выбирается из
четырёх; на задачу уходит одна-две минуты. Тексты — из сборников, которым полтора века:
«Пословицы русского народа» и «Толковый словарь живого великорусского языка» Владимира
Даля, загадки Дмитрия Садовникова. Каждая решённая задача оставляет после себя строку:
откуда она, что значит, как говорили раньше.

Каждый день — **одна задача дня, общая для всех**; результат можно отправить другу
текстом, как принято в словесных играх, — без картинок и без регистрации. Остальное —
**тетради** по темам: «О труде», «О доме», «Загадки о природе», «Старые слова» — решаются
в любом порядке и в любое время. Без таймеров, жизней и «энергии». Работает без интернета.

Деньги — **реклама между задачами** (не посреди задачи, не в первый день и никогда после
задачи дня) и одна покупка **«Буквица+»**: без рекламы навсегда и все тетради
([`10-money.md`](10-money.md)). Это шестая игра студии «Горница» и, вместе с «Нардами»,
та, которая **должна окупаться с первых месяцев**: контент — общественное достояние,
сервера нет, движок — несколько экранов и чистая логика. На сайте студии она обещана
в разделе «В планах» ([gornitsa.games](https://gornitsa.games/)); обещания сайта — это
обязательства.

## Название

Рабочее название — **«Буквица»**. У Даля *буквица* — «стар. азбука, букварь; ныне же
так называют старинные славянские письмена» (Толковый словарь, т. 1, 2-е изд., 1880,
с. 141); в книжном деле буквица — большая узорная начальная буква. Оба значения — наши:
игра про буквы и про старые слова, а знак игры — узорная буква в духе брендбука.
В магазине — **«Буквица — пословицы, загадки, старые слова»**: главные слова поиска
стоят в названии.

Что проверить до карточки (владелец, В1 в [`07-roadmap.md`](07-roadmap.md)):

- Знаки «Буквица» в классах МКТУ 9 и 41 по базе ФИПС. Слово общеупотребимое, но знак
  с ним может быть.
- В RuStore уже есть приложения «Буквица» (учебное, книга) и «Древнеславянская Буквица» —
  приложения неоязыческого толка про «49 букв» (поиск RuStore, 04.10.2026). Нашей игре
  это соседство не на руку: в описании мы прямо говорим, что опираемся на Даля
  и Садовникова, а не на «ведические» толкования. Если владелец сочтёт соседство
  неприемлемым — запасные названия: «Красное словцо», «Присловье», «Складно».

В коде и документах проект называется **«Буквица»** (`bukvitsa`), чтобы смена названия
в магазине не требовала правок по репозиторию (ADR [0001](adr/0001-studio-adrs.md),
применение ADR студии 0006).

## Для кого

Портреты — гипотезы; их проверяют первые недели после выхода ([`11-market.md`](11-market.md)).

1. **Женщина 35–65 лет, которая отдыхает с телефоном.** Решает кроссворды в газете
   и «Слова из слова» на телефоне; любит, когда задача про родное — пословицы, которые
   говорила бабушка, слова, которые слышала в деревне. Не хочет полутораминутной рекламы
   после каждого уровня и «купите 500 монет». Это ядро словесного жанра в RuStore
   и главный источник покупок «Буквица+».
2. **Учитель, библиотекарь, родитель школьника.** Ищет, чем занять детей и себя
   «с пользой»: загадки и пословицы — школьная программа, старые слова — олимпиадные
   вопросы. Делится задачей дня в родительском чате.
3. **Тот, кто любит русский язык.** Читает Даля для удовольствия, знает, что такое
   «буквица» и «голик». Для него игра — ежедневная минутка с источником и строкой
   «откуда это».
4. **Человек в дороге без интернета.** Электричка, метро, дача: все тетради работают
   без сети; задача дня — тоже, календарь встроен в игру.

## Что обещаем игроку

- **Задача дня — всегда бесплатно и без рекламы.** Одна на всех, каждый день, навсегда.
  Пропущенный день не пропадает: прошлые задачи дня лежат в архиве и решаются когда
  угодно (ADR студии 0010 — ничего не сгорает).
- **Спокойно.** Ни таймеров, ни жизней, ни «энергии», ни серий, ни наград «за вход».
  Задачу можно отложить и вернуться; подсказки бесплатные; ответ можно открыть — задача
  просто считается подсмотренной, а не решённой.
- **Реклама — только между задачами** и только после первого дня; никогда посреди
  задачи, никогда после задачи дня; никаких баннеров. **«Буквица+» убирает рекламу
  навсегда** одной покупкой — не подпиской.
- **Ничего не покупается за силу.** Подсказки не продаются. Покупка открывает тетради
  и убирает рекламу — и всё.
- **Каждая задача — с источником.** Пословица — с разделом сборника Даля, слово —
  со страницей словаря, загадка — с изданием. Ничего «из интернета» и ничего по памяти
  (ADR студии 0012, [`09-content.md`](09-content.md)).
- **Без интернета, без регистрации, без слежки.** Профиля нет, сервера нет; игра не
  знает, кто вы. Рекламная сеть получает только то, без чего не покажет ролик, и это
  записано в политике конфиденциальности ([`10-money.md`](10-money.md), «152-ФЗ»).
- **Крупно и ясно.** Крупные буквы, контраст, никаких мелких кнопок: игра рассчитана
  на тех, кому за пятьдесят, и на дорогу.
- **Поддержка отвечает по существу** — support@gornitsa.games.

## Чего в продукте сознательно нет

- **Игровой валюты, монет, сундуков** — ни за деньги, ни за просмотр (ADR студии 0009).
- **Подсказок за деньги или за ролик.** Ролик по желанию открывает *задачи* — ещё десять
  из любой тетради, — а не силу ([`08-game-design.md`](08-game-design.md), «Ролик по желанию»).
- **Таймеров, жизней, энергии, серий и ежедневных наград** (ADR студии 0010).
- **Рейтингов, лиг и соревнования с чужими людьми.** Результат дня — текст, которым вы
  делитесь сами; никаких таблиц лидеров и профилей.
- **Генерированных задач.** Каждая задача сделана руками по источнику и проверена
  человеком; машина только собирает и проверяет.
- **Английской версии и сборки для других стран.** Игра — про русский язык; текста для
  перевода нет (ADR [0006](adr/0006-russian-only.md)).
- **Сервера.** Ни профилей, ни облачных сохранений, ни «задачи дня с сервера»
  (ADR [0002](adr/0002-daily-calendar-offline.md)).
- **Уведомлений** в 1.0. Если появятся — только локальные, по согласию, одно в день
  («задача дня готова»), и никогда «мы соскучились».

## Как называются вещи

| Слово | Что это |
|---|---|
| **Задача** | одна головоломка: условие, ответ, источник, подсказки и строка «откуда это» |
| **Вид задачи** | один из пяти: пословица, загадка, лишняя буква, старое слово, по частям ([`08-game-design.md`](08-game-design.md)) |
| **Ряд букв** | буквы ответа вперемешку с лишними; ответ складывается из них по одной |
| **Тетрадь** | тематический набор задач (около сорока) с обложкой и названием; решается в любом порядке |
| **Первая тетрадь** | тетрадь, которая бесплатна всегда |
| **Задача дня** | одна задача на всех, назначенная календарю; бесплатна и без рекламы |
| **Календарь** | таблица «дата → задача» на годы вперёд, собранная при сборке и неизменная после выпуска |
| **Архив** | прошлые задачи дня; решаются в любое время |
| **Подсказка** | бесплатное действие в задаче: убрать лишние буквы, открыть букву, показать ответ |
| **Решена / подсмотрена** | задача решена сама или с открытым ответом; отличаются значком |
| **Откуда это** | строка после решения: источник, значение, иногда — как говорили в старину |
| **«Буквица+»** | одна покупка: без рекламы навсегда и все тетради, нынешние и будущие |
| **Ролик по желанию** | реклама за награду, которую игрок включает сам: ещё десять задач из закрытой тетради |
| **Запись** | файл контента в `content/`: одна задача с источником и статусом проверки ([`09-content.md`](09-content.md)) |
