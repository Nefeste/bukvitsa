# Путь к 1.0 «Буквицы»

Живая спецификация. Решение владельца 08.11.2026 (Nefeste/uprava#80, вариант 1): «Буквица» — одна из двух следующих
мобильных игр, выход в RuStore — к середине декабря, к рекламе студии на праздниках (`uprava#81`). Разделы — по
уставу, [`11-new-games.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/11-new-games.md#2-прототип).

## 1. Зачем

Ответить делом на два вопроса:

1. **Затягивает ли пословица как задача?** Хочется ли завтра открыть задачи дня — без серий, таймеров и наград.
2. **Можно ли сделать словесную игру без спора со словарём и без продажи подсказок** — и чтобы она зарабатывала
   рекламой между задачами тетрадей.

## 2. Что берём из игр студии

[`02-architecture.md`, §2](../02-architecture.md#2-что-скопировано-из-игр-студии-adr-студии-0002): каркас, токены,
шрифты, настройки, хранение, CI — из «Наготове»; хеш и генератор — из «Сказов» и «Анамнеза»; реклама и деньги
(0.3) — по образцу «Нард» и из `gornitsa-kit`.

## 3. Сквозной путь игрока

| № | Шаг | Бюджет |
|---|---|---|
| 1 | Запуск → первый экран: буквица, «Задачи дня · дата», пять пустых кружков | ≤ 2 с холодный запуск |
| 2 | «Решать» → задача 1 (лёгкое слово) | ≤ 60 с |
| 3 | «Дальше» → задачи 2–5 | ≤ 4 мин всего |
| 4 | Итог дня → «Поделиться» → мессенджер | ≤ 20 с |
| 5 | «В начало» → «Тетради» → тетрадь → задача | ≤ 30 с до первой задачи |
| 6 | «Прошлые дни» → вчерашний день → задачи | ≤ 15 с |
| 7 | Закрыть и открыть игру — всё решённое на месте | — |

Весь день — **до 5 минут**.

## 4. Ощущение — как проверить числами

| Что | Число | Как проверить |
|---|---|---|
| Касание плитки — буква на месте | ≤ 100 мс | замер на телефоне владельца |
| Первая задача дня решается без подсказки | у владельца — да, в 4 днях из 5 | игра владельца, 5 дней |
| День без подсказок и ошибок | у владельца — 3 из 5 задач в среднем | игра владельца |
| Задача, которую «не понять» (обидная, непонятная, «нечестная») | не больше 1 на 20 | проверка задач человеком |
| Желание открыть завтра | владелец говорит «да» | вопрос к игре владельца |

## 5. Обёртка

Первый экран с буквицей и названием; «Об игре» с источником и почтой поддержки; «Настройки» с «Меньше движения»;
иконка и заставка без белой вспышки (0.2); «Назад» телефона везде ведёт понятно.

## 6. Жизнь мира

Нет и не нужно: игра — страница книги. Живость — в смене задач каждый день и в зимних пословицах на праздниках.

## 7. Графика и звук

Всё — кодом и шрифтами студии ([`13-art.md`](../13-art.md)); растровых картинок нет. Звук касания плитки — по
желанию владельца в 0.2, синтез скриптом с проверкой байт в байт (как в «Наготове»); выключатель — в настройках.

## 8. Бюджет

- Целевой телефон — телефон владельца, один на все игры студии (ADR устава 0023, `uprava#74`): 60 кадров по медиане
  при прокрутке тетради и архива, кадров дольше 25 мс — не больше 1 %. Недорогой опорный телефон только запускает игру
  и проходит путь §3 без вылетов.
- Анимированной сцены нет; на экране — до 40 элементов (плитки, места, кнопки).
- Содержание в сборке — до 400 КБ JS; APK — **до 40 МБ** (проверяет сборка тега); холодный запуск — до 2 с.

## 9. Чего в 1.0 нет

Загадок и «Слова по Далю» (нет текста источника), английского языка, уведомлений, облачного сохранения, сервера,
рейтингов, звука (если владелец не попросит), анимаций.

## 10. Критерии готовности

1. Сценарий в браузере проходит путь §3 целиком без ошибок в консоли (`npm run e2e`).
2. Тесты зелёные: движок, ход решения, календарь, содержание, настройки, строки, версия.
3. Сборка содержания без ошибок; в календаре — не меньше 120 дней от даты выпуска; тетрадей — 8 по 30.
4. Каждая задача — из источника, с разделом; одна пословица — одна задача; запретных слов нет.
5. Задачи проверены человеком (`review: checked`) — или решение владельца выпустить с черновиками.
6. Решены деньги (реклама и «Буквица+»), название (ФИПС), идентификатор приложения.
7. APK подписан постоянным ключом, проверки набора `gornitsa-kit` зелёные, размер ≤ 40 МБ.
8. **Игра владельца:** пять дней задач дня и одна тетрадь на телефоне; ответы на вопросы §11.

## 11. Вопросы к игре владельца

- Хочется ли открыть задачи дня завтра? Что тянет — или ничего?
- Какая задача была «нечестной»: слово не угадать по смыслу, конец подходит не один, пословица непонятна?
- Какой вид задач нравится больше, какой — меньше?
- Пять задач в день — много, мало, в самый раз?
- Делились бы вы итогом? С кем?

## 12. Решения агента

| Что | Почему | Как переделать |
|---|---|---|
| Пять задач дня, а не одна (на сайте было «Задача дня — одна») | строка из пяти кружков — то, чем делятся; один вид задач надоедает; день — до 5 минут | `DAY_SLOTS` в `tools/content/pick.ts`, `08-game-design.md` §2; текст на сайте — с карточкой игры |
| Текст Даля — из Викитеки, скачан в репозиторий | единственный цельный оцифрованный текст издания 1862 года, доступный из песочницы; сборка без сети | `tools/content/fetch.ts` |
| Задачи подбирает скрипт, проверяет человек | 990 задач руками — недели; скрипт детерминирован, запись — правится | `tools/content/pick.ts` |
| Скрытое слово — самое обиходное в пословице | его можно угадать по смыслу; редкое слово — угадайка | `gapOf` |
| Задачи дня — сперва пословицы с самыми частыми словами | первые дни — для новичка | `commonness` в `tools/content/pool.ts` |
| Части — только по знакам препинания | кусок «Птицу по» не похож на часть пословицы | `partsOf` |
| Кружки итога рисуются, а не значками шрифта | «◐» в шрифте выглядит по-разному и криво | `Marks` в `src/ui/kit.tsx` |
| Перерешать задачу ради лучшего кружка нельзя | итог честный | `startPlay` |
| Календарь — с 1 декабря 2026 года, 150 дней | на выходе в середине декабря — две недели «прошлых дней» в запасе; до весны | `content/calendar.yaml` |
| Без роутера: восемь экранов состоянием | как «Наготове»; меньше зависимостей | `App.tsx` |
| Идентификатор `games.gornitsa.bukvitsa` в `app.json` | по образцу других игр; вечный — подтверждает владелец до первого подписанного APK | Issue |
