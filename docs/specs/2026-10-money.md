# Деньги: реклама и «Буквица+»

**Версия:** 0.5.0 **Состояние:** задумано

## Зачем

Игра должна зарабатывать с первого месяца: реклама между задачами и одна покупка
«Буквица+». Правила — ADR [0003](../adr/0003-money-ads-plus.md), числа —
[`../08-game-design.md`](../08-game-design.md), «Реклама» и «„Буквица+“ глазами игрока»,
право и SDK — [`../10-money.md`](../10-money.md).

## Проверка по обещаниям

Преимущество за деньги — нет (подсказки бесплатны, покупка — контент и отсутствие
рекламы). Реклама посреди игры — нет (только между задачами, никогда у задачи дня).
Сервер и данные — рекламная сеть получает только то, что записано в политике; согласие
на персональную рекламу — отдельным экраном. Остальное не относится.

## Что увидит игрок

- **Экран согласия** при первом ролике (не при запуске): «Реклама помогает игре быть
  бесплатной. Показывать персональную рекламу?» — две равноправные кнопки
  «Персональную» / «Только обычную», ничего не отмечено, ссылка на политику. Ответ —
  в настройках.
- **Ролик между задачами**: после «Откуда это» при нажатии «Ещё», если движок
  разрешил; перед роликом — короткий экран «Реклама · „Буквица+“ убирает её навсегда»
  на 1 секунду (единственное упоминание покупки у рекламы, п. 3 списка мест).
- **Закрытая тетрадь**: обложка, «Открыть в „Буквице+“» и «Десять задач за ролик»
  (если В3 — да); после ролика счётчик тетради «открыто 10 из 40».
- **Экран «Буквица+»**: что входит, «249 ₽ — один раз, не подписка», «Купить»,
  «Восстановить покупки», статус RuStore (не установлен / не вошли).
- После покупки: рекламы нет, тетради открыты, на главной вместо «Буквица+» — «Спасибо».

## Данные

`rights.plus`, `rights.plusCheckedAt`, `settings.adsConsent`, события `ad` и `tens` —
в схеме 1, миграции нет. Идентификаторы рекламных блоков — в `app.json` (конфиг
плагина), ставит владелец.

## Устройство

`src/money/ads.ts` (адаптер; SDK — копия из «Нард») и `src/money/pay.ts` (RuStore Pay,
копия из «Нард»); оба — пути владельца. Экран вызывает `ads.showInterstitial()` только
при `engine.adAllowed(..., 'between') === true`; `ads.showRewarded()` — только с кнопки.
Веб — заглушки с счётчиками для сценария.

## Неудачные случаи

- Нет сети / сеть не отдала ролик — игра продолжается молча; «десять задач» без ролика
  не открываются, кнопка — «Нужен интернет».
- Ролик закрыт до конца (за награду) — награды нет, кнопка снова доступна.
- RuStore не установлен или не вошли — экран покупки говорит об этом; всё бесплатное
  работает.
- Покупка подтверждена, но сверка при запуске не удалась (нет сети) — права по
  сохранённому состоянию; сверка — при следующем запуске с сетью.
- Сеть требует разрешение сверх белого списка — красная сборка; решение владельца
  до включения.

## Критерии приёмки

- Тесты границ рекламы ([`../06-testing.md`](../06-testing.md), §2) зелёные; сценарий:
  ролик не вызывается у задачи дня, внутри задачи и после покупки; вызывается после
  десятой задачи на второй день (сценарий переводит «сегодня» аргументом).
- Экран согласия без отмеченного ответа; ответ сохраняется и меняется в настройках.
- Тестовая покупка RuStore Pay на телефоне владельца: покупка, перезапуск, восстановление
  на втором устройстве.
- Раздел политики с рекламой и анкеты `store/forms.md` обновлены в том же PR
  (путь владельца).
- Разрешения APK — белый список + `AD_ID`, ничего сверх.

## Чего здесь нет

Платных тетрадей по отдельности, подписки, рекламы на вебе (Яндекс Игры — 1.2),
отчётности по рекламе в игре.
