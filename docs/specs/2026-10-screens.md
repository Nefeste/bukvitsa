# Экраны и первая тетрадь

**Версия:** 0.2.0 **Состояние:** задумано

## Зачем

Из движка и записей собрать игру, которую можно поставить на телефон и открыть
в браузере: главная, задача, «Откуда это», тетрадь, настройки, «Об игре»; прогресс
сохраняется и переживает обновления; первая тетрадь решается целиком. Это первая
сборка, которую кто-то ставит на телефон, — с неё `applicationId` и ключ подписи
постоянны (ADR студии 0006).

## Проверка по обещаниям

«Зовёт, торопит, стыдит» — нет: на экранах нет счётчиков, серий, окон при запуске.
Остальные вопросы к этой версии не относятся (денег и сети нет).

## Что увидит игрок

Экраны по таблице [`../08-game-design.md`](../08-game-design.md), «Экраны», кроме
«Архив» и «Буквица+» (0.4, 0.5). На главной в 0.2 вместо задачи дня — «Первая тетрадь»
сверху; тетради, кроме первой, показаны закрытыми без кнопок открытия (надпись
«В следующих версиях»).

- **Задача**: условие от 22 pt, ряд плашек 48 dp, три подсказки под рядом, верхняя
  стрелка «Назад» (прогресс задачи не сохраняется — задача начинается заново).
- **Откуда это**: полный текст, источник одной строкой, `about`; «Ещё» и «На главную».
- **Тетрадь**: обложка (SVG кодом), «12 из 40 · 2 подсмотрены», список задач значками.
- **Настройки**: звук (в 0.2 — выключатель без звуков), «ещё крупнее», тема,
  «Сообщить об ошибке» (копия из «Вотчины»), «Удалить мои данные» с подтверждением
  своим диалогом.
- **Об игре**: версия, знак студии, «Откуда тексты» (источники по
  [`../09-content.md`](../09-content.md), §1), лицензии шрифтов, ссылка на политику.

Вид — по брендбуку; тёмная тема с первой версии; портрет на телефоне.

## Данные

`bukvitsa.json` со `schema: 1` — [`../04-data-model.md`](../04-data-model.md), «Телефон».
Образец файла — в `tools/test/fixtures/saves/schema-1.json`.

## Автоматика

`android.yml` (копия из «Узоров»): APK на тег, подпись постоянным ключом, `--release`-
контент. `site.yml`: закрытая веб-версия `gornitsa.games/bukvitsa/test/` под паролем,
nginx на сервере сайта — по образцу `deploy/uzory/` в репозитории сайта.

## Неудачные случаи

- Файл сохранения повреждён — игра начинает с чистого состояния, повреждённый файл
  переименовывается в `bukvitsa.broken.json` для «Сообщить об ошибке».
- Экран не помещается на маленьком телефоне (менее 360 dp ширины) — ряд переносится
  на две строки; тест сценария проверяет 360 × 640.

## Критерии приёмки

- Сценарий Playwright [`../06-testing.md`](../06-testing.md), §5 (без «Поделиться»
  и закрытых тетрадей) зелёный на веб-сборке от корня и для `/bukvitsa/test`.
- Первая тетрадь решается целиком, прогресс переживает перезапуск и обновление
  с предыдущей сборки.
- APK ставится и работает без сети; `applicationId` = `games.gornitsa.bukvitsa`;
  разрешений сверх белого списка нет.
- Контраст текста ≥ 4,5 : 1 в обеих темах (проверка в сценарии по вычисленным цветам).
- Строки для игрока только в `src/i18n/` — тест зелёный.

## Чего здесь нет

Задачи дня и архива (0.4), рекламы и покупки (0.5), звуков (0.6), снимков для магазина.
