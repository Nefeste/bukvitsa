# Движок: пять видов задач

**Версия:** 0.1.0 **Состояние:** задумано

## Зачем

Вся логика игры — проверка ответа, подсказки, права, правила рекламы, календарь — должна
быть чистыми функциями, которые проверяются тестами без телефона и без React, чтобы
экраны были тонкими, а правила из [`../08-game-design.md`](../08-game-design.md) —
проверяемыми по одному тесту на каждое число.

## Проверка по обещаниям

Вопросы устава к движку не относятся, кроме двух: случайности в движке нет (ряд и порядок
приходят из задачи); правила рекламы в движке держат «не посреди задачи, не в первых».

## Что увидит игрок

Ничего нового: 0.1 — это веб-прототип одного экрана «Задача», где можно решить задачу
каждого из пяти видов из `content/`, чтобы проверить руками ощущение ряда букв и
подсказок. Прототип не хранит прогресс.

## Устройство

`src/engine/` — функции без состояния; типы — [`../04-data-model.md`](../04-data-model.md):

| Функция | Что делает |
|---|---|
| `check(task, input)` | `'right' \| 'wrong'`; нормализует регистр, ё/е по правилу задачи, дефис |
| `hint(task, state, n)` | состояние после подсказки `n` (1 — убрать лишние, 2 — открыть букву/часть, 3 — ответ); `peeked` после третьей |
| `place(task, state, letter \| part \| option)` / `unplace(...)` | ход игрока в ряду, частях, вариантах, строке |
| `progress(events)` | решённые, подсмотренные, «n из m» по тетрадям, последний ролик |
| `canOpen(task, notebook, rights, events)` | `'open' \| 'plus' \| 'tens'` |
| `adAllowed(events, rights, now, context)` | по границам «Реклама»; `context` — `'between' \| 'daily' \| 'task' \| 'archive'`: всё, кроме `'between'`, — всегда `false` |
| `daily(calendar, today)`, `archive(calendar, today)` | задача дня и прошлые |
| `shareText(task, event, date)` | текст «Поделиться» |

Все входы — аргументы: дата, время, права, события; `Date.now()` и `Math.random()`
в папке запрещены линтером.

## Данные

Новых файлов хранилища нет (0.1 без сохранения). Образцы задач для тестов —
`tools/test/fixtures/tasks.json`, собранные сборкой из двух записей-образцов `content/`.

## Неудачные случаи

- Задача с неизвестным `kind` — сборка не пропускает; движок бросает ошибку на
  этапе загрузки набора, не в игре.
- Ответ с буквой не из ряда — `place` игнорирует.
- Календарь не содержит сегодняшней даты — `daily` возвращает `undefined`; экран
  показывает «Обновите игру — новые задачи дня в новой версии» (случай за концом
  календаря).

## Критерии приёмки

- Тесты [`../06-testing.md`](../06-testing.md), §2, все зелёные; покрытие границ
  рекламы — по тесту на каждую строку «Реклама» в геймдизайне.
- Веб-прототип решает по одной задаче каждого вида из `content/` без ошибок в консоли.
- `npx tsc --noEmit`, линтер — ноль предупреждений; запрет `Date.now`/`Math.random`
  в `src/engine/` — правилом линтера.

## Чего здесь нет

Экранов, хранилища, рекламы и покупки (только правила для них), звука.
