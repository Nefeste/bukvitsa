# Что запускать перед тем, как сказать «готово»

| Команда | Что проверяет |
|---|---|
| `npm run content` | сборка содержания и все проверки записей ([`09-content.md`](09-content.md#4-проверка-сборкой)) |
| `npm run typecheck` | содержание + типы приложения и инструментов |
| `npm run lint` | линтер без предупреждений |
| `npm test` | содержание + `bun test tools/test` |
| `EXPO_OFFLINE=1 npm run export:web && npm run e2e` | веб-сборка и сценарий в браузере, снимки в `tools/e2e/out/` |

`pr.yml` гоняет первые четыре на каждом PR; сценарий в браузере — сборка тега и агент перед push, если менялись экраны.
Chromium для сценария — `CHROMIUM_PATH` или установленный Playwright.

## Тесты (`tools/test/`)

| Файл | Что держит |
|---|---|
| `engine.test.ts` | слова и промежутки; задачи четырёх видов одинаковы у всех; проверка ответа; даты календаря без `Date`, високосные годы; архив; строка итога |
| `play.test.ts` | ход решения: верно сразу, ошибка (верные буквы запираются), подсказки до конца, «Показать ответ», решённая открывается решённой; конец, части, лишняя буква |
| `content.test.ts` | разбор Даля (скобки, ударения, границы пословиц, страницы скана), запретные слова, сборка без ошибок, полные тетради, запас календаря ≥ 120 дней, одна пословица — одна задача, черновики |
| `settings.test.ts` | настройки и итоги: битое отбрасывается; «меньше движения» по системе и по выбору; анимация — только с `useLessMotion()`; вибрации нет |
| `i18n.test.ts` | кириллица — только в `src/i18n` (и алфавит в `src/engine/letters.ts`) |
| `version.test.ts` | номер версии одинаков в пяти местах, у версии есть раздел в README |

## Сценарий в браузере (`tools/e2e/browser.ts`)

Дата — `?date=2026-12-01`. Первый экран → пять задач дня (первая — с подсказкой, «конец» — с ошибкой) → итог и текст
«Поделиться» без ответов → прошлые дни → тетрадь «Зима и праздники»: задача и «Показать ответ» → настройки → об игре →
перезагрузка: итоги сохранились. Ответы сценарий берёт из движка — так он проверяет, что экран показывает ту же
задачу. Ошибка в консоли — провал.

## На телефоне (делает владелец)

- Сквозной путь дня — до 5 минут; одной рукой; текст читается при крупном шрифте телефона.
- Замер кадра на целевом телефоне (ADR устава 0023): прокрутка тетради и архива без рывков.
