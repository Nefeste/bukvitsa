# Документация «Буквицы»

Здесь лежит всё, что нужно, чтобы вести проект, ничего не помня о нём заранее.
Документация живёт в репозитории рядом с кодом и меняется вместе с ним: правка кода
без правки документа — незакрытая задача. Устройство документов — общее для студии
([`docs/04-process.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/04-process.md)
устава); отличия оговорены там, где они есть.

**Сейчас кода нет** (решение владельца 04.10.2026: только документы и карточка «В планах»
на сайте). Документы `02`–`04` и `08`–`09` описывают задуманное устройство. С первой
строки кода они описывают то, что есть, а расхождение с кодом правится в том же коммите.

## Как мы работаем

Как во всех проектах студии: «сначала спецификация, потом код», ADR, версии и выпуск —
по уставу. У «Буквицы», как у «Узоров» и «Анамнеза», есть **второй поток работы —
задачи**: они добавляются записями в `content/` по правилам [`09-content.md`](09-content.md),
каждую проверяет сборка, а в выпуск она идёт после сверки со сканом и `review: checked`
от человека ([`05-process.md`](05-process.md), «Два потока работы»).

## Правила этих документов

Общие правила документов студии — в уставе: русский язык, одно место для факта, задуманное
помечено, гипотезы отделены от фактов, комментарии в коде — про «почему». Как они
применены здесь:

- **Одно место для факта.** Числа геймдизайна — только в `08`; правила задач и источники —
  только в `09`; форматы — в `04`; деньги и право — в `10`; рыночные цифры — в `11`.
  В остальных местах — ссылка.
- **Гипотезы** — цены, eCPM, цели удержания, размеры тетрадей — помечены словом
  «гипотеза». Взятое из поисковой выдачи без первоисточника помечено [в] — сверить.
- **Факты с датой**: карточки RuStore сняты 04.10.2026; тексты Даля сверены с Викитекой
  04.10.2026 (сверка со сканом — отдельно, в записях).

## Карта репозитория (задуманная)

```
App.tsx                переключатель экранов
app.json               Expo: идентификатор, версия, плагины (подпись, RuStore Pay, реклама, резервная копия)
src/engine/            задачи, подсказки, права, правила рекламы, календарь — чистый TypeScript
src/content/           generated/pack.ts — встроенный набор (не в git); типы записей
src/state/             прогресс (события), настройки, права, хранилище, миграции
src/screens/           главная, задача, откуда это, тетрадь, архив, «Буквица+», настройки, об игре
src/ui/                плашка-буква, диалог, тема, узорная буква и обложки (SVG)
src/money/             RuStore Pay и адаптер рекламы — путь владельца
src/i18n/              тексты интерфейса
content/               записи задач (YAML), тетради, календарь, стоп-лист, выпущенные версии
assets/                шрифты, два звука, иконка
plugins/               плагины конфигурации Expo
tools/content/         сборка задач, проверки, «виртуальный игрок», календарь, выпуск
tools/test/            тесты движка, контента, файлов, текстов, автослияния
tools/e2e/             сценарий Playwright на веб-сборке
tools/store/           иконка, снимки для магазина
store/                 материалы RuStore и страница сайта
docs/                  эта документация
.github/               CODEOWNERS, проверки на PR, автослияние, сборка на тег, закрытая веб-версия, RuStore
```
