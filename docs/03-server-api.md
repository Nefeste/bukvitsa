# Сервер и сеть

**Сервера у «Буквицы» нет** — ни в 1.0, ни в планах до 1.3 (ADR
[0002](adr/0002-daily-calendar-offline.md)). Всё, что делает игра, делается на телефоне:
задачи встроены, календарь встроен, прогресс лежит в памяти телефона, права считаются
по данным RuStore Pay. Документ существует, чтобы устройство документов было одинаковым
во всех проектах, и чтобы было одно место, где записано, **что всё-таки ходит в сеть**.

## Что выходит в сеть и куда

| Кто | Куда | Когда | Что |
|---|---|---|---|
| RuStore Pay SDK | RuStore | при запуске (сверка покупки), в «Буквице+», «Восстановить покупки» | сведения об оплате по правилам RuStore; почту и идентификатор игрока игра не передаёт |
| RuStore Review SDK | RuStore | когда игра просит оценку ([`08-game-design.md`](08-game-design.md), «Оценка в RuStore» — после второй решённой тетради, один раз) | по правилам RuStore |
| рекламный SDK | рекламная сеть | ролик между задачами; ролик по желанию | то, без чего сеть не покажет ролик; подробно — [`10-money.md`](10-money.md), «152-ФЗ» |
| «Сообщить об ошибке» | почтовое приложение игрока | по кнопке | письмо, которое игрок отправляет сам: версия, модель телефона, журнал сбоев, его текст |
| веб-сборка | gornitsa.games | открытие страницы | обычная загрузка страницы; журнал сервера — без адресов, как у «Узоров» |

Своей статистики на сервере нет: счётчики, по которым проверяются гипотезы
([`08-game-design.md`](08-game-design.md), «Как поймём…»), считаются на телефоне и видны
игроку на экране «Об игре» («Решено 120 задач, 30 дней подряд не обязательно»). На
закрытом тесте тестеры присылают эту строку сами; в магазине источник цифр — статистика
RuStore (установки, удаления, оценки) и отчёт рекламной сети (показы). Если этого
окажется мало — вопрос владельцу о счётчике по образцу «Узоров» (ADR студии 0008:
без идентификаторов, раз в сутки, на машину студии), с правкой политики до выпуска.

## Если сервер всё же понадобится

Поводы, при которых вопрос открывается заново (и только они):

- задачи дня с сервера, чтобы менять их без выпуска версии, — нет: календарь на три
  года и выпуск раз в месяц решают это дешевле;
- наборы задач по сети, когда встроенный набор перерастёт разумный размер, — по образцу
  «Узоров» ([`03-server-api.md`](https://github.com/Nefeste/uzory/blob/main/docs/03-server-api.md)
  того репозитория): статические файлы, каталог с подписью, счётчики без идентификаторов;
- «вдвоём по ссылке» — отдельное решение с ADR, профилем по ADR студии 0007 и с 14 лет
  (ADR студии 0016).

Любой из них — новый ADR, правка этого документа, раздел политики и машина студии
в России (ADR студии 0005).
