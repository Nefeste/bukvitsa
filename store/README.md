# Магазин и сайт

Всё, что нужно карточке «Буквицы» в RuStore и странице игры на gornitsa.games. Пока игра
«В планах» и кода нет, здесь — **черновики**: тексты по документам, без графики и снимков
(они пересоздаются скриптами из кода игры, когда он появится — `tools/store/`).

| Файл | Что | Как обновить |
|---|---|---|
| [`listing.ru.md`](listing.ru.md) | название, краткое и полное описание, ключевые слова для RuStore | руками; длины сверяет `tools/test/store.test.ts` (с 0.2) |
| [`forms.md`](forms.md) | ответы для анкет RuStore: возраст, реклама, покупки, данные, разрешения | руками, вместе с кодом; путь владельца |
| `graphics/icon-512.png`, `feature-ru.png`, `cover-site.png` | иконка 512 × 512, баннер 1024 × 500, обложка 1920 × 640 | `bun tools/store/graphics.ts` (с 0.6) |
| `screenshots/ru/*.png` | снимки экрана 1080 × 1920 | `npm run export:web && bun tools/store/shots.ts` (с 0.6) |
| [`site/`](site/) | страница игры на gornitsa.games и карточка на главной — формат устава (ADR студии 0015); черновик раздела политики | руками, [`site/README.md`](site/README.md) |

Правила текста — устав, `docs/08-publishing.md`, «Материалы игры»: обещания студии словами
игры, голосом студии; никаких чужих названий игр; слово «бесплатно» — с оговоркой, что
платно.
