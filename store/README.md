к 1.0; значок, баннер и снимки собираются скриптами `tools/store/` из кода и веб-сборки (08.11.2026).

| `screenshots/ru/*.png` | семь снимков 1080 × 1920 (9 : 16): пословица, «Откуда это», конец пословицы, лишняя буква, тетрадь, главная, части в тёмной теме | `npm run content && EXPO_OFFLINE=1 npm run export:web && bun tools/store/shots.ts` |
