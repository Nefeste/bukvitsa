# Страница «Буквицы» на gornitsa.games

[`page.ru.md`](page.ru.md) и [`page.en.md`](page.en.md) — страница игры на сайте студии и её
карточка на главной: поля и текст по формату устава (`Nefeste/gornitsa`, `docs/08-publishing.md`,
раздел «Сайт»; ADR студии 0015). Картинки — из `../graphics/` и `../screenshots/ru/`, те же,
что в карточке RuStore; WebP нужных размеров сайт делает сам.

**Пока игра «В планах»**, сайт эту папку не читает: карточка «В планах» написана руками
в репозитории сайта (`src/index.html`, `src/en/index.html` в `Nefeste/gornitsagames`).
Когда разработка начнётся (0.2, первая сборка и закрытая веб-версия), игру добавляют
в `tools/games.json` сайта, карточку «В планах» убирают, и дальше сайт раз в сутки забирает
эту папку с `main` и открывает PR — сливает владелец. До того страницы здесь — черновики
без картинок; поля `icon`, `feature`, `cover`, `shots` добавляются вместе с графикой
(`status: dev` на сайте не выйдет без них — формат проверяет `tools/test/site.test.ts`).

Черновик раздела «Буквица» в политике конфиденциальности студии (`#bukvitsa` в
`src/privacy.html` сайта) появится здесь к 0.6 как `privacy-bukvitsa.ru.md` и переносится
на сайт до закрытого теста (устав, `docs/07-privacy.md`); сайт его не читает.
