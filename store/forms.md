# Ответы для анкет RuStore (черновик)

Готовый текст для консоли RuStore к 1.0. Каждый ответ — утверждение о коде или о решении
из документов; поменялось одно — поменять другое в том же коммите. Где справку RuStore
сверить не удалось, стоит **[проверить]**. Путь владельца (`CODEOWNERS`).

## Разрешения APK

`INTERNET`, `ACCESS_NETWORK_STATE` — реклама и покупка; `com.google.android.gms.permission.AD_ID` —
рекламный идентификатор для рекламной сети (добавляет её SDK); `VIBRATE` — отклик.
Остальное вырезано и проверяется в CI по белому списку `tools/test/permissions.json`:
файлы, камера, микрофон, местоположение, контакты, показ поверх окон, фоновая работа.

## Данные (если консоль спросит)

| Вопрос | Ответ | Почему |
|---|---|---|
| Собирает ли приложение персональные данные? | **Само — нет**; рекламная сеть обрабатывает рекламный идентификатор и сведения об устройстве для показа рекламы по своей политике; персональная реклама — только с согласия игрока на отдельном экране | `docs/10-money.md`, «152-ФЗ» |
| Передаёт ли третьим лицам? | только рекламной сети (см. выше) и RuStore (оплата) | — |
| Покупка | обрабатывает RuStore; игра знает только «куплено» | `docs/10-money.md` |
| Отчёт об ошибке | игрок отправляет сам письмом; игра ничего не отправляет | `docs/03-server-api.md` |
| Аналитика | нет; сервера у игры нет | ADR 0001 |

Политика конфиденциальности — раздел «Буквица» общей политики студии:
`https://gornitsa.games/privacy.html#bukvitsa`. Черновик раздела — `site/privacy-bukvitsa.ru.md`
(появится к 0.6); **выложить на сайт до закрытого теста**.
